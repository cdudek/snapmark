### Scrolling capture exploration — not a finding

A browser extension is not inherently required. [Shottr documents screen-level scrolling capture](https://shottr.cc/kb/scrollingcapture), using Screen Recording for pixels and Accessibility for automated scrolling; manual scrolling is an alternative. [CleanShot documents scrolling capture](https://cleanshot.com/features), and its [API exposes autoscroll](https://cleanshot.com/docs-api).

For Snapmark, an optional mode would need overlap matching, stable-content detection, stop/cancel, preview and clear limits for sticky elements, animation, nested scrolling and lazy loading. These are implementation inferences, not a tested prototype. Ordinary region capture should remain the default.

Current long-edge resizing would make a very tall stitched image tiny. Splitting it into readable session entries deserves evaluation before adding capture stitching. “Ocra” could not be reliably identified, so no comparison was invented.
