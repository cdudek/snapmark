# Snapmark glossary proposal

Every term the product shows, where it appears, and the one word proposed for it. Filled in by the audit of 2026-09-25 (v0.2.0).

**A proposal, not decided.** One word per meaning and one meaning per word, everywhere: the menu, the
editor, session.md, notifications, the copied prompt, the PDF and the README. What the copied prompt says
is given in the notes, because the prompt is where the agent learns the words.
